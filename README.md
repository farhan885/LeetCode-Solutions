## How to use

Clone the repo and open any solution file directly — each file contains the solution function and is named after the problem for easy reference:

```bash
git clone https://github.com/farhan885/LeetCode-Solutions.git
```

Files follow the naming pattern:
```
Leetcode#<number>.<Problem_Title>
```
